# 保留教师讲法：编辑边界与补讲策略

## 对原录音做什么

**原始转写示例（故意包含卡顿）：**
> “现在我们这个，那个，先看这个 p 啊，p 它是这个基因的那个，频率，频率。然后这个，二倍体里面有两份嘛，所以这个等位基因，嗯，所以他每代抽样会变。”

**可接受的整理：**
> “现在我们先看 p。p 是这个等位基因在群体中的频率。二倍体个体有两份等位基因，所以每代随机抽样以后，这个频率就可能发生变化。”

**不可接受的重写：**
> “本页知识点为Wright–Fisher模型的频率演化定律。核心结论如下：……”

对听不清的术语，只在PDF、TeX和清楚的相邻录音能够支持时修复。老师自己的独特比喻，只要不明显跑题，应保留。老师不严谨的日常口语可以做最低限度文字清理，但不要更换推理路线。

## 补讲怎么做

1. 先确定这页**新增可见元素**，不要凭上一页的整个frame生成一份重复讲稿。
2. 观察老师在参考材料里怎样从上一项过渡、怎样提问、怎样口头解释公式；沿用相同的节奏（不是抄套话）。
3. 如果本页缺录音，可以从当前可见符号的意义说起，再说明一个局部推导或与前一页的关系。课件没出现的数字或案例不要自己发明。
4. 对于图示动画只新增箭头/标注，补讲往往只需一两句说明新增箭头指向什么；不能为了平均字数填一大段。
5. 在来源台账写 `simulated`，主稿不标“AI补写”“这里没录到”；用户拿起主稿就能直接讲。

## 忌讳

- 连续多页套用“上一页我们已经……这一页我们继续……”模板。
- 长篇解释“本模型不能证明”“课件未提到所以我不讨论”等打断口播的自我辩解。
- 保持总字数却在多个overlay页复制几乎一样的段落。
- 先口头讲出下一帧的最终结论，再在下一帧重新解释一遍。
- 用书面语强行替换老师本来很自然的短句和设问。
