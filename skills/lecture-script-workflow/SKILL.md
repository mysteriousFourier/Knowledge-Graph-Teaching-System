# 逐页课堂讲稿整理（中文）

**触发时机**：用户提供课堂录音/录像/逐字稿、PDF课件和（可选）参考讲稿、TeX/PPT源文件，希望整理成能直接照读的逐页中文讲稿。也适用于录音覆盖不完整、录音压缩包里有多场课、课件含动画逐帧展开等情况。

**不要用于**：单纯课堂摘要、问答题解答、普通字幕校对或逐字原文转录，除非用户明确要求转为逐页讲稿。

## 目标与交付

默认交付：
1. `课程名_逐页讲稿_XXX页.md`：**唯一供授课朗读的主文件**。页标严格为 `## 第1页`、`## 第2页` …… `## 第XXX页`；每页内是紧凑、自然的连续口语正文，不写出处标记，不插入TeX或提纲格式。
2. `课程名_对齐记录.csv`：内部核验文件，记录各页PDF可见内容、对应录音时间、内容属于原录音还是模拟补讲、是否有疑点。**补写不得冒称教师实际说过。**
3. `课程名_验收报告.md`：简洁呈现PDF总帧数、总字数、漏页/重页、公式残留、疑似错页和无法确认的部分。能在同一答复中直接交付完整文件时，不让用户反复输入“继续”。

这三个文件可以作为一次性输出；用户只要主讲稿时，两个核验文件可以内部生成但不必主动单独展示。

## 0. 输入优先级与启动

- PDF **实际渲染页面**负责最终页码、标题、图表、公式、每次overlay显示的新内容；不要让TeX frame数取代PDF页数。先用 `fitz.open(pdf)`/`pdfinfo`核对总页数，使用 `scripts/slide_index.py` 生成每页索引及缩略图；必要时查看原尺寸截图。文本提取只作辅助，不能代替页面视觉核对。
- **匹配的课堂录音/逐字稿**决定授课内容、叙述顺序、提问、举例和具体措辞。原有讲法是第一优先，不重新设计课程。
- **参考讲稿**只提供该授课者已建立的整理格式、节奏、口语风格；不能反向“创造”本次录音中不存在的真实话语。
- TeX/PPT源码（如果有）用来核对公式、术语及动画机制；图像与页序以PDF为准。
- 用户提供的其他资料仅用于被明确请求的外部扩充。不要用网上内容擅自替换讲义。

如果有多个转录文件：解包列出全部候选；逐个比较标题、关键词、课程章节次序、特征公式及录音时间。优先选**与PDF主题、前后次序和内容覆盖匹配的**版本，不能只按文件名日期推断。记录匹配理由。若全部不匹配，按PDF进行模拟授课并在验收报告中明确说明，不要伪称“原录音整理”。

录音是音视频而非转录文本时，应使用可用的语音识别能力先做带时间戳的转录和说话人分离；逐字稿要做专业术语纠错。不能读取或转写时，明确区分“仅PPT模拟讲稿”与“依据录音整理”，不要假装听过录音。

## 1. 建立逐页对齐台账

必须先创建 `page = 1...P` 的固定页面清单（可用 `scripts/slide_index.py`）。每页至少记录：PDF标题、当页新增/变化的视觉内容、关联录音片段、对齐置信度、内容来源。

- Beamer 的 `frame` 可以展开为多个独立PDF页面；每个PDF页面必须且只对应一个 `## 第X页`。同一 frame 的前一页已有内容，可以在后续页自然衔接，但不要机械重复上一页整段讲稿。
- 对比每一页与上一页新出现的公式行、图示、注释箭头、强调项；如图片是嵌在PDF中的，必须看渲染图，不要只依赖OCR/提取文本。
- 录音可先切成约5—15分钟的主题片段，再依据课件推进顺序精配到页；讲者可能停留在同一页很久，也可能连续翻几页。根据语义定位，不能按总时长平均分配。
- 一个录音自然段跨越多个overlay页时，在它对应的内容首次出现页开始承接，把讲述按思路分到相邻页，避免中断一句完整推理；只有PDF确实显示的新信息才能提前揭示。
- 对齐每10—20页复核一次页面图像、讲稿主题和最后已匹配的录音时间；发现错位先修正，不得带错位继续推进。
- PDF真实存在但录音未覆盖的页面也必须逐页保留。课件确实几乎无新增内容时，可以短讲一两句自然过渡；不能捏造公式、例子或声称“这是空白页”来跳过。

来源标签只存在台账中：`recorded`（直接有录音覆盖）、`adapted`（根据录音前后内容轻度衔接）、`simulated`（按课件与授课风格模拟补讲）、`transition`（实际显示很少新信息的自然过渡）。绝不把 simulated 写成录音原句。

## 2. 整理录音：轻校订，禁止重讲

目标是“把老师说出来的话变得可读”，不是“用AI重新解释知识”。阅读 `references/style_fidelity.md` 确认轻校订边界及补讲标准。

- **保留**原讲解顺序、类比、具体例子、对学生的设问和回答、重要的课堂旁白、推导节奏、老师惯用的连接方式。自然口语是可取的。
- **删除**“呃”“那个”等无意义语气词、卡顿、连续复读、未完成口误和无效的自我修正；音识别错词结合PPT更正（如漂变/基因座/加性/等位基因）。
- 如果一句话虽然不够“教材化”但意思明确，应保留其讲法；不得擅自将口语重构成书面知识点。若语义因ASR噪声不可判定，用PDF定界修复最小必要词语，不创造新的定量结论。
- 不使用“这一页讲的是……”“下面进入……”“核心结论是……”“XXX原理：”等模块化开头；不写AI总结或防御型自我解释。
- 不为了字数而重复解释同一事实。除非是录音里教师有目的地回顾，或新overlay引入新的比较角度。

## 3. 录音不完整时的教师风格补讲

允许且需要依据**当页真实PDF内容**模拟教师完整讲课，使每一帧都能朗读。**这是创作性补写，不是历史转录**，故将其来源在独立台账标为 `simulated`。

优先继承：(1) 当前课程教师在相近概念上的提问/推理方式；(2) 参考讲稿和真实录音中的句长、口吻、术语；(3) 前后页衔接。先讲清PPT当前可见概念、公式和推导，再用已出现的例子做延伸；不要从互联网上自创案例、引入未经课件支持的研究结果或伪造老师的个人经历。

对于录音只讲到半个推导的情况：保留原句的讲法和示例，补足PDF后续实际写出的步骤；**不把一半内容全部改成新的统一讲解**。课件与录音存在科学或符号冲突时，优先忠实反映实际PDF、对明显ASR错误校正；无法确认的逻辑问题记入验收记录，不在朗读稿中无依据地装作确定。

## 4. 公式必须转为可直接朗读的中文

最终讲稿**不含TeX公式**（包括行内 `$...$`、`\(...\)`、`\[...\]`、`\frac`、`\sigma` 等）。不是简单删掉数学，而是保留每个运算关系并改为自然中文话语。示例：

- `H_t = H_0 (1-1/(2N))^t` → “第 t 代杂合度等于初始杂合度，乘以一减二 N 分之一的 t 次方。”
- `E[X^2]-E[X]^2` → “X 平方的期望，减去 X 的期望的平方。”（不能误读为“期望平方减期望平方”）
- `Q_{ST}>F_{ST}` → “Q S T 大于 F S T。”
- `∑_{i=1}^n a_i` → “从 i 等于一到 n，把每一个 a 下标 i 加起来。”
- `\chi^2_{n-1}` → “自由度为 n 减一的卡方分布。”
- `\sigma_B^2` → “西格玛 B 平方”，符号第一次出现时可说明“群体间方差”。

对于复杂括号、分式、求和，先阅读 `references/oral_math_guide.md`，再在脑中核对运算优先级，再用“括号里……”“整个……除以……”使听者不会误解；不连续念一串无解释的符号。如果公式在PPT里分帧出现，朗读稿也分帧推进，不在前一页提前把最终结果读完。

## 5. 排版与长度

主文件严格使用 `## 第X页`，按实际PDF页码从1连续到P。每页通常一到两个自然段，尽量不额外空行、不插入横线、不插入表格、列表、脚注、来源注释或公式块。标题页和目录页短；公式页中等；信息密集页长。保持一口气可读，不写大段教材。

**默认沿用用户此前的 32000 字最低目标**（可由用户覆盖）。这是全文目标而不是每页配额；必须靠真实PPT信息、自然推导和缺页补讲满足，绝不能用重复段落、虚构内容和空泛修辞凑数。如果在给定材料下无法合理达到，明确报告实际字数及资料限制，不虚报。

## 6. 交付前必须执行的核验

使用 `scripts/audit_script.py` 检查页码、页数、字数、TeX标记、异常空页、连续重复和禁止式开头。脚本只负责**机械质量检查**；另需人工/模型按PDF截图逐页抽查首、中、尾及高风险页，检查页码是否对应、图片/公式是否讲对、是否有幻觉补写。台账必须覆盖所有PDF页且来源标记准确。核验通过后只提供一个完整主讲稿下载链接；若用户希望可追溯，也附台账和简短报告。

**最终回复**应简短，说明总页数、实际字数、补讲范围和未能确认的事项。不得宣称“完全对应老师原话”除非确实有录音覆盖；不得声称自动脚本能验证语义对齐。

## 7. 失败时的处理

- **录音匹配失败**：不要强行套错；选择完全依据PDF模拟讲解，并显式标注来源为模拟。
- **PDF提取页数不稳定**：以实际PDF渲染工具核实，不按TeX frame估算，不依赖截断的文本预览。
- **逐字稿缺时戳**：允许按术语、公式和章节语义匹配，但时间范围留空，不虚构时间。
- **图表内文字无法机器提取**：渲染检查，必要时高分辨率页面图；不能凭标题猜。
- **长文件上下文/执行限制**：将每一段及时追加到同一个磁盘文件、保存当前已完成页号与已用录音段；恢复时只续写，不覆盖已验证部分；最终交付时检验全文件。
