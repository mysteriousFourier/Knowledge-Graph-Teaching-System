# 数学公式中文口播规范（供生成讲稿时参考）

## 目的

讲稿是老师在课堂上直接朗读的正文，不是公式索引。PDF或TeX中的公式应保留数学关系，但最终以自然口语表达。首次出现新的大符号时自然解释含义，随后使用惯用简称。

## 关键对照

| 原式（核对专用，不能原样留在主稿） | 口播建议 |
|---|---|
| `H_t=H_0(1-1/(2N))^t` | “第 t 代的杂合度，等于最初的杂合度，乘以一减二 N 分之一的 t 次方。” |
| `E[X^2]-E[X]^2` | “X 平方的期望，减去 X 的期望的平方。” |
| `Var(\bar z)` | “表型均值的方差。”或“z 均值的方差。” |
| `\sigma_p^2(t)` | “第 t 代等位基因频率的方差。” |
| `\sigma_B^2(t)` | “第 t 代群体间的方差。” |
| `\sigma_A^2(0)` | “最初的加性遗传方差。” |
| `\widehat\sigma_B^2` | “群体间方差的估计值。” |
| `\chi^2_{n-1}` | “自由度为 n 减一的卡方分布。” |
| `F_{L-1,\infty}` | “分子自由度为 L 减一、分母自由度趋于无穷大的 F 分布。” |
| `Q_{ST}>F_{ST}` | “Q S T 大于 F S T。” |
| `\sum_{i=1}^n a_i` | “把从 i 等于一到 n 的每一项 a 下标 i 加起来。” |
| `x/y` | “x 除以 y。”或“y 分之 x”，统一使用易于理解的读法。 |
| `e^{-t/(2N_e)}` | “以 e 为底，指数是负的 t 除以二 N e。”适当说明“这是随时间衰减的指数项”。 |

## 不能改变的数学区别

- “X 平方的期望”与“X 的期望的平方”不是一回事。
- “一减二 N 分之一的 t 次方”会产生括号歧义，应在复杂表达时说“括号里的一减二 N 分之一，整体取 t 次方”。
- 分子/分母存在求和、加减时，先说清“整个分子”“整个分母”；不能把分母的一部分错读到分子。
- “西格玛 B 平方”第一次可补一句“表示群体间方差”，之后优先用“群体间方差”而不是一遍遍拼字母。
- 写有条件分布的 `X~N(0,1)` 应说“X 服从均值为零、方差为一的正态分布”，不要念代码。
- 因为课件有动画分步显示公式，讲稿也应一步一步讲，不得提前朗读后续帧才出现的表达式。

若一个特别长的公式逐字符朗读会难以理解，允许将它准确拆成“第一项……、第二项……，二者相加”的自然语言，并解释公式里变量代表什么；不允许忽略决定结论的运算、条件或系数。
